# 🌹 Rosae - O Simbolismo das Rosas

O **Rosae** é uma página web criada para explorar e compartilhar os significados e sentimentos associados às diferentes cores das rosas. O projeto foi desenvolvido com HTML5 semântico e CSS3 puro, aplicando conceitos de Flexbox e responsividade para dispositivos móveis e tablets.

---

## 🎨 Funcionalidades e Seções

- **Hero / Banner**: Apresentação inicial com imagem de fundo e menu de navegação.
- **Galeria de Flores**: Cards interativos com resumos das rosas (Amarela, Branca e Azul).
- **Saber Mais**: Blocos detalhados com layouts alternados entre imagens e descrições.
- **Sobre**: Propósito da página.
- **Contato**: Formulário para envio de mensagens.
- **Rodapé**: Direitos autorais e logótipo.

---

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação semântica.
- **CSS3**:
  - Variáveis CSS (`:root`) para cores e gradientes.
  - **Flexbox**: Alinhamento de elementos e criação de layouts dinâmicos.
  - **Media Queries (`@media`)**: Design adaptativo para telemóveis e tablets.
  - Efeitos de `hover` e transições sutis.

---

## 📱 Responsividade

- **Desktop**: Layout expansivo com menu horizontal e elementos lado a lado.
- **Tablets (`769px` - `1024px`)**: Reorganização dos cards e proporções de texto adaptadas.
- **Smartphones (`<= 768px`)**:
  - Menu e cabeçalho empilhados na vertical.
  - Imagens posicionadas no topo dos textos para facilitar a leitura.
  - Ajuste de margens e padding para navegação fluida em ecrãs pequenos.
